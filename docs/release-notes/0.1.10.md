## Flat keys with clear animation

- The permanent 3D effect is removed. Keys look flat again, as in version 0.1.5.
- Fast touch feedback remains visible: a brief scale and contrast change follows the original web version. Key shape and rounding are preserved.
- Short touches, multiple fingers and canceled input remain correctly handled.

## Development and build checks

- GitHub Actions and build steps use Node.js 24, removing the warning about the obsolete Node 20 runtime.
- Full Windows, Linux, Chromium, Firefox and WebKit checks continue to run on `main` and before releases.
- Successfully checked `main` builds publish automatically to the separate Cloudflare development address. Production still updates only through releases.

Existing calculations and preferences are retained. The development address has its own data, separate from production.
