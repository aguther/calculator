## Improvements

- Larger, more readable digits and compact history rows with minutes beside the value.
- Groups with headings, indentation, connector lines and highlighted results.
- Revised mode selection, a centered desktop layout and history on the right by default; the setting now moves the entire panel.
- Improved iPhone safe areas and spacing down to the smallest desktop window size.
- Missing or failing haptic support no longer interrupts the app.
- An unchanged second tab no longer overwrites newer calculation state during updates.

## Installation

The [browser version](https://calculator.andreas-7f3.workers.dev) can be installed as a PWA. Existing installations remain usable while an update downloads; activate the completed version through the update notification.

Windows x64: extract the ZIP and run `calculator.exe`. Linux x64: extract the tarball and run `calculator`; see the [system requirements](https://github.com/aguther/calculator/blob/v0.1.2/docs/desktop.md). SHA-256 checksums are in `SHA256SUMS.txt`.

Safari/iPhone does not provide vibration through the browser API used here. Missing or failing APIs and safe areas are covered by automated WebKit tests; testing the installed PWA on a real iPhone is still useful.
