## Improvements

- Settings follow the calculator's look and feel, with rounded cards and a revised theme selector.
- Animated iOS-style switches for history, key sounds and supported haptics.
- A wrapping theme grid leaves room for additional themes.
- Updates use a compact button in a dedicated header position, without reserving space at the bottom. It is hidden while Settings is open.
- The interface uses the full available height, without an artificial 860-pixel limit.

## Downloads

[Open the browser/PWA version](https://calculator.andreas-7f3.workers.dev). Accept the available update in an existing PWA. Windows x64: extract the ZIP and run `calculator.exe`. Linux x64: extract the tarball and run `calculator`; see the [system requirements](https://github.com/aguther/calculator/blob/v0.1.3/docs/desktop.md). Checksums are in `SHA256SUMS.txt`.
