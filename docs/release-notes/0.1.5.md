## Changes

- Match the iOS status-bar mode to the working original web PWA: `black` instead of `black-translucent`.
- Avoid the differing configuration that introduced an additional 62 px of top system spacing in the reported comparison.
- Add screen dimensions and further viewport values to diagnostics.
- Add a build contract test and browser reference case for 402×812 with 0 px top and 34 px bottom system spacing.

[Open the browser/PWA version](https://calculator.andreas-7f3.workers.dev). Restart an existing PWA through the offered update. On the affected iPhone, check the bottom edge and diagnostics afterwards. iOS may retain installation metadata; reinstalling is not a confirmed general fix and can remove saved calculations.

Windows x64: extract the ZIP and run `calculator.exe`. Linux x64: extract the tarball and run `calculator`; see the [system requirements](https://github.com/aguther/calculator/blob/v0.1.5/docs/desktop.md). SHA-256 checksums are in `SHA256SUMS.txt`.
