# Upcoming changes for 0.1.11

These notes describe the upcoming version; it has not been published yet.

## German and English interface

- The app supports German and English on desktop and in the browser.
- The initial language follows the system or browser locale. A manual language selection in Settings is saved on the device.
- Existing calculations and preferences remain compatible.

## Windows application icon

- The Windows executable embeds a multiresolution application icon for Explorer and shortcuts, using images from 16 to 256 px derived from the existing 512 px artwork.
- The native window continues to use the 512 px PNG. Icon generation and verification are documented for maintainers.

## English developer documentation

- Repository documentation, code comments and developer-facing explanations are in English, with expanded Rust API documentation and meaningful identifiers.
- New contributor onboarding and an architecture/source map explain setup, persistence compatibility, touch/render flow, PWA updates, tests and release gates.
- Historical release notes, UI investigations and benchmarks are available in English, preserving their measurements and limitations.
- Deployment documentation clarifies that checked `main` builds deploy only to `calculator-dev`; production remains restricted to version-tag releases.
