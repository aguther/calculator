## Faster, straighter key presses

- Press feedback still reacts immediately but returns much faster after release: the extra hold phase is removed and the return animation lasts only 60 ms.
- The key face moves only vertically and no longer contracts sideways.
- Key shape and rounding are unchanged; only press feedback is adjusted.
- Clear touch feedback, unchanged hit targets, and handling of short/canceled touches are retained.

## Informative release descriptions

- Releases use maintained, version-specific change lists instead of only automatically generated comparison links.
- Descriptions for 0.1.7 and 0.1.8 now include their concrete changes.

Existing calculations and preferences are retained.
