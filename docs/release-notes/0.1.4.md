## Changes

- Original Lucide `undo-2`, `delete` and `refresh-cw` icons for undo, delete and update, embedded for offline use.
- Done remains visible while scrolling in Settings.
- PWA height follows the visible browser area, with additional viewport diagnostics for iOS.
- Browser audio unlocks directly during a user gesture; subsequent WASM input reuses the prepared audio context.

## Notes

[Open the browser/PWA version](https://calculator.andreas-7f3.workers.dev). Use the offered update button to update an existing PWA.

Actual audio playback and the height correction still require confirmation on the affected iPhone. Automated browser and regression tests do not replace this device check.

Windows x64: extract the ZIP and run `calculator.exe`. Linux x64: extract the tarball and run `calculator`; see the [system requirements](https://github.com/aguther/calculator/blob/v0.1.4/docs/desktop.md). Checksums are in `SHA256SUMS.txt`.
