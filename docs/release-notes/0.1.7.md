## Easier settings navigation

- New General, Controls and Diagnostics tabs replace the small expandable sections.
- General groups the color scheme and existing toggles. Tabs and Done stay reachable while scrolling.
- Shortcut help presents useful special keys. **F2** selects time mode and **F3** number mode; each retains its own calculation.
- Diagnostics are easier to read and can be copied as a complete report.
- Buttons show press feedback. The version display is larger; the additional local-storage notice is removed.
- Fast keyboard input immediately after closing settings is no longer lost. F1–F3 do not open browser help or search in the calculator.

## Availability

The web app and Windows/Linux packages were updated with this version. Existing calculations and preferences are retained.
