# Embedded fonts

Noto Sans Regular and SemiBold, unmodified, from [notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSans), revision `ffebf8c1ee449e544955a7e813c54f9b73848eac`.

SIL Open Font License 1.1; full text in `OFL.txt`, also included in packaged third-party notices. Both fonts are embedded in WASM and native executables, with no runtime download. The two weights improve small text and numeric readability consistently across platforms.
